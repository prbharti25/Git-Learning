# Git and GitHub Learning

A hands-on collection of Git and GitHub practice created while learning version control and collaborative development workflows.

## About This Repository

This repository contains practical examples and notes for understanding how Git tracks changes and how GitHub is used to store, share, and collaborate on software projects.

## Topics Covered

- Installing and configuring Git
- Creating and initializing repositories
- Checking repository status
- Staging files with `git add`
- Creating commits with `git commit`
- Viewing commit history with `git log`
- Reviewing changes with `git diff`
- Restoring and resetting changes
- Reverting commits safely
- Working with branches
- Connecting local repositories to GitHub
- Pushing and pulling changes
- Understanding remotes and collaboration workflows

## Common Git Workflow

```bash
git status
git add .
git commit -m "Describe the changes"
git push
```

## Useful Commands

```bash
git log --oneline
git diff
git branch
git remote -v
git pull
git push
```

## Learning Goals

- Track project changes with confidence
- Maintain a useful commit history
- Practice branch-based development
- Understand the relationship between Git and GitHub
- Build a reliable workflow for future projects
